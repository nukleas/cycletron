# awesome-livecoding — full catalog snapshot

Source: <https://github.com/toplap/awesome-livecoding> (captured 2026-06-05).
This is an archive of the list, lightly reorganized. Inactive projects are marked.
Cycletron-relevant entries are flagged with **⭐**.

## Audio-focused languages

- **Alda** — music programming language for musicians. https://github.com/alda-lang/alda
- **Bacalao** — SuperCollider lib with Tidalcycles-style syntax. https://github.com/totalgely/bacalao
- **Cane** — MIDI sequencer DSL with euclidean rhythms. https://github.com/Jackojc/cane
- **ChucK** — concurrent, strongly-timed music language. http://chuck.cs.princeton.edu/
- **clive** — live audio coding in C. https://mathr.co.uk/clive/
- **Extempore** — cyberphysical programming environment. https://extemporelang.github.io
- **FoxDot** ⭐ — Python/SuperCollider live coding. http://foxdot.org/
- **Renardo** — FoxDot fork with new features. https://renardo.org/
- **Sonic Pi** — live coding synth for education. http://sonic-pi.net/
- **SuperCollider** — audio synthesis platform. http://supercollider.github.io/
- **TidalCycles** ⭐ — Haskell pattern language (Strudel's parent). https://tidalcycles.org/
- **Strudel** ⭐ — web-based Tidal-style patterns (the upstream of strudel-rs). https://strudel.cc

## Visual-focused languages

- **Hydra** ⭐ — browser-based networked visuals (relevant to visualizer.ts). https://github.com/hydra-synth/hydra
- **Punctual** ⭐ — audiovisual web language. https://github.com/dktr0/Punctual
- **Cyril** (inactive) — fast prototyping for visualizations. http://cyrilcode.com/
- **Fluxus** — 3D graphics/sound environment. http://www.pawfal.org/Software/fluxus_/
- **LocoMotion** — dance/choreography/3D visuals. https://github.com/dktr0/LocoMotion

## Hybrid / multi-modal languages

- **Glicol** ⭐ — graph-oriented Rust language (WASM). https://glicol.org/
- **Mégra.rs** ⭐ — LISP/Rust with Markov chains. https://github.com/the-drunk-coder/megra.rs
- **Sardine** ⭐ — Python library (MIDI/OSC/SuperDirt), strong patterning system. https://github.com/Bubobubobubobubo/Sardine
- **Mercury** ⭐ — minimal algorithmic music language. https://github.com/tmhglnd/mercury
- **Topos** ⭐ — Teletype-inspired web environment. https://topos.live/
- **Estuary** ⭐ — multilingual collaborative platform (hosts mini-Tidal). https://estuary.mcmaster.ca
- **Gibber** — creative coding for JavaScript. https://gibber.cc/
- **ORCΛ** — 2D-syntax esoteric sequencer language. https://github.com/hundredrabbits/Orca
- **ossia score** — interactive sequencer w/ custom visual language. https://ossia.io/
- **Trane** — browser-based Janet livecoding. https://lisp.trane.studio

## Notable additional languages

- **afterglow** — lighting controller in Clojure. https://github.com/brunchboy/afterglow
- **Coypu** — Pharo Smalltalk music programming. https://github.com/lucretiomsp/Coypu
- **Facet** — NodeJS environment, browser editor. https://github.com/mjcella/facet
- **kilobeat** — DSP bytebeat-inspired instrument. https://ijc8.me/kilobeat
- **Limut** — browser music/visuals. https://github.com/sdclibbery/limut
- **loopmaster** ⭐ — WebAssembly DSP with visualizations. https://loopmaster.xyz
- **Mosaic** — openFrameworks visual patching. https://mosaic.d3cod3.org/
- **Mercury / Motifn / Melrōse** — JS/golang music environments.
- **Overtone** — audio env via SuperCollider/Clojure. http://overtone.github.io/
- **Pure Data** — visual sound/graphics programming. https://puredata.info/

## Libraries & tools (selected, Cycletron-relevant)

- **total-serialism** ⭐ — algorithmic-composition toolkit (JS). https://tmhglnd.github.io/total-serialism/
- **isobar** ⭐ — Python composition/pattern library. https://github.com/ideoforms/isobar
- **Supriya** — Python/SuperCollider API. https://github.com/josiah-wolf-oberholtzer/supriya
- **Strudel Flow** ⭐ — node-based Strudel UI. https://xyflow.com/strudel-flow
- **strudel.nvim** ⭐ — Neovim controller for Strudel. https://github.com/gruvw/strudel.nvim
- **Petal** — Sonic Pi TidalCycles-like layer. https://github.com/siaflab/petal
- **tidal-chord** — chord add-on for Tidal. https://github.com/fp4me/tidal-chord
- **TidalFX** — Tidal effects package. https://github.com/calumgunn/TidalFX
- **Flok** ⭐ — P2P collaborative editor (multiplayer livecoding). https://munshkr.github.io/flok
- **Extramuros / EspGrid** — networked buffer/clock sync for ensembles.
- **Hydra / The Force / VEDA / Bonzomatic / KodeLife** — shader/visual coding tools.
