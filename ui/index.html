Welcome

Robostrudel

AI-first strudel music engine. A quick tour, then you're free.

  • ⌘⇧P command palette — every action, every file
  • ⌘O / ⌘S open / save
  • ⌘↩ play · Esc stop
  • ⌘F find · ⌘⇧F replace

Anthropic API key

Paste your key to enable the AI composer. You can change this any time in Preferences.

Leave blank to read ANTHROPIC_API_KEY from the environment instead.

Library location

Where Robostrudel keeps the patterns you save and the MIDI conversions you import. You can move it later from Preferences.

You're all set

The cyan panel on the left is the AI Operator; the next one is your file system. The toolbar above the editor has Record, MIDI Lab, and History.

If anything breaks, Help → Show Logs gives you a copy-and-paste diagnostic dump for bug reports.
